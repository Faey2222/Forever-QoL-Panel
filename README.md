# Forever QoL Panel

An all-in-one quality-of-life addon for World of Warcraft: Forever, designed to look like part of the base game.

- Info panel with integrated XP bar (rested XP, quest preview) and selectable elements
- Minimap button collector
- Action bars: new spells and higher ranks placed automatically
- Quest markers on nameplates
- Gameplay helpers: auto quests, most valuable reward marked, sell grey items, repair, fast loot, loot text
- Buff and consumable warnings
- Tooltip extras: sell value, item counts per character, gathering skill
- Own options window with search and a setup wizard

Every feature can be switched off on its own. Open the options with `/fqp`, the setup wizard with `/fqp setup`.

## Development

- `ForeverQoLPanel/` is the addon folder. `tools/deploy.ps1` links it into the game's AddOns folder for testing.
- `python tests/smoke.py` loads the addon against a mocked WoW API.
- `tools/` holds the scripts that build the textures in `ForeverQoLPanel/media/`. Raw client art is downloaded to
  `tools/.cache/` and never committed.
