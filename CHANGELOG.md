### Forever QoL Panel 1.1.3 – Selling and bag fixes

#### Fixes
- **Selling grey items:** uses the merchant's own "sell all junk" where the game offers it, since the game may block an addon selling item by item. The chat message now only counts what was really sold; if nothing could be sold, it tells you to use the merchant's junk button
- **Bag slots:** free slots are now counted slot by slot, so an empty profession bag no longer shows 0 free in red
