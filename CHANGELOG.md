### Forever QoL Panel 1.2.0 – Reputation bar, move mode and mail recipients

#### New
- **Reputation bar:** for the faction you watch, in the XP bar's look, only finer. Attached to the XP bar (with its shadow), as an own bar below it or placed freely; at the highest level it takes the XP bar's place. Ticks, status text (faction, standing, points, percent) and its own options page
- **Move mode with grid:** one mode for everything that can be placed (warning groups, loot text, bars set free). Frames snap to the grid while you drag them; grid size and snapping can be set. Start it with `/fqp move` or from the options
- **XP bar set free:** the XP bar (with the reputation bar) can leave the panel and stand anywhere
- **Mail:** an arrow next to the recipient lists your other characters on this realm and faction, with first and last name
- **Characters:** a new options page lists the characters the addon knows; ones that no longer exist can be removed
- **Addon menu:** can show only its icon and arrow

#### Fixes
- **Reward values and money messages** show coins (gold, silver, copper) instead of a plain copper number
- **Most valuable reward:** its coin is fully visible
- **Gathering tooltip:** your profession skill is found reliably, so herbs, veins and skinnable creatures no longer show "too low" in red by mistake
